# Project instructions

## Language

- Communicate with the user in Vietnamese, including progress updates, explanations, questions, and final responses, unless the user explicitly requests another language for a particular response.
- Write application code in English, including identifiers, comments, and developer documentation.
- Use English for all application-facing text, including the desktop interface, settings, tooltips, status messages, activity logs, errors, CLI output, and packaged instructions.
- Keep these preferences separate: English application text does not change the conversation language, and Vietnamese conversation does not change the application language.
